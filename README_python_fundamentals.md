# Python Fundamentals — Assignment Solutions

Solved notebook for the Python Fundamentals assignment covering variables, dynamic typing, common data types, object identity, strings, loops, conditions, functions, and scope. It also includes all 11 scenario-based questions.

## File
- `python_fundamentals_assignment_solutions.ipynb` — complete code solutions and explanations.

## Run
Open the notebook in Jupyter Notebook, JupyterLab, Google Colab, or VS Code. Run cells from top to bottom. The input-based question (Q6.4) will ask for a number. Questions designed to demonstrate errors catch and display the expected exception so the notebook can continue running.

## Topics
- Variables and dynamic typing
- Data types, lists and tuples
- Objects, equality and identity
- String methods
- `for`, `while`, and `range()`
- Conditions and modulo
- Functions, arguments, and return values
- Local and global scope
- Scenario-based practice

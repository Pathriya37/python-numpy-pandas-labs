# Pandas DataFrames — Lab Practice Solutions

Solutions to all 30 questions in the Pandas DataFrames lab practice sheet.

## Run the notebook

1. Open `pandas_dataframes_lab_solutions.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or Google Colab.
2. Ensure Pandas and NumPy are installed (`pip install pandas numpy`) if running locally.
3. Run cells from top to bottom.
4. For Questions 15, 25, and 30, copy a table with headers before running `pd.read_clipboard()`. Clipboard access may not work in all cloud notebook environments.

The solutions use example student, book, employee, product, course, travel, school, and inventory data.

# NumPy Laboratory Practice — Solutions

This repository contains a Jupyter Notebook with solutions to all 43 questions in the NumPy Laboratory Practice sheet.

## Topics Covered
- Array creation and properties
- Array arithmetic
- Indexing, slicing, views and copies
- 2-D indexing and slicing
- Reshaping and transpose
- Matrix operations
- NumPy universal functions
- `np.where()`
- Statistical operations and axes
- Sorting and unique values
- Integrated array and matrix challenges

## Main file
`numpy_lab_practice_solutions.ipynb`

## Requirements
Python 3 and NumPy. Install NumPy with:

```bash
pip install numpy
```

Open the notebook in Jupyter Notebook, JupyterLab, Google Colab, or VS Code and run the cells from top to bottom. Random examples use fixed seeds for reproducible results where appropriate. File-handling and array input/output topics are excluded, as specified in the assignment.

# NumPy and Pandas Series — Lab Practice Solutions

This repository contains solutions to 40 practical questions covering NumPy arrays and Pandas Series.

## How to run
1. Open `numpy_pandas_series_lab_solutions.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
2. Ensure NumPy and Pandas are installed (`pip install numpy pandas`).
3. Run the cells from top to bottom.

The difficult-section questions use fixed random seeds for reproducible results.

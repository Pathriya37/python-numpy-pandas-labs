# Pandas Series – Practice Question Set (Solutions)

This repository contains solutions to 30 practice questions based on the Pandas Series concepts covered in Lec 14 – Series.ipynb.

## Sections
- Section A – Easy: Questions 1–15
- Section B – Medium: Questions 16–25
- Section C – Hard: Questions 26–30

## Topics covered
- Creating Series and viewing values/index
- Label-based selection and filtering
- Series names and index names
- Dictionary conversion and reconstruction
- Missing data with `isnull()` and `notnull()`
- Index membership and index alignment during arithmetic

## Main file
Open `pandas_series_practice_solutions.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or Google Colab.

## Requirements
Python 3 and Pandas. Install Pandas with:
```bash
pip install pandas
```
